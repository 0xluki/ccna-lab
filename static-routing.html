Step 9

Static Routing

Goal. Connect the user LANs to a second router and the server network.
Concept. Routers only know directly connected networks. A static route tells a router “to reach network X, send to next-hop Y”. It is simple and has administrative distance 1, but never adapts to failures, and routes are needed in both directions or replies are lost.
Before you start. DHCP working. Cable R1 G0/1–R2 G0/0 and R2 G0/1–Server.

Your tasks

  1. Address the point-to-point link: R1 G0/1 = 192.168.10.241/30, R2 G0/0 = 192.168.10.242/30. Add no shutdown.
  2. R2 G0/1 = 172.16.1.1/24. Server: 172.16.1.10/24, gateway 172.16.1.1.
  3. On R1 add a route to 172.16.1.0/24 via 192.168.10.242.
  4. On R2 add one summary route to 192.168.10.0/24 via 192.168.10.241.
  5. Ping the server from PC1, then run traceroute 172.16.1.10.
  6. Finally remove both static routes (no ip route ...) — OSPF replaces them next.

Hints

Hint 1

Syntax: ip route <network> <mask> <next-hop>.

Hint 2

The next hop is the neighbour’s address on the shared link.

Hint 3

Why summarise on R2? One /24 route covers all four VLAN subnets.

Verify

Command / testExpected result
show ip route staticS 172.16.1.0/24 [1/0] via 192.168.10.242 (on R1)
ping 172.16.1.10 (from PC1)Success
