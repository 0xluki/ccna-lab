Access Control Lists – full solution

Try the hints first. Type the commands yourself rather than pasting, because that is how they stick.

R1

ip access-list extended SERVER-FILTER
 permit ospf any any
 deny ip 192.168.10.128 0.0.0.63 host 172.16.1.10
 permit tcp 192.168.10.0 0.0.0.255 host 172.16.1.10 eq 80
 permit udp 192.168.10.0 0.0.0.255 host 172.16.1.10 eq 53
 permit icmp 192.168.10.0 0.0.0.255 host 172.16.1.10
 permit tcp 192.168.10.224 0.0.0.15 any eq 22
interface g0/1
 ip access-group SERVER-FILTER out
ip access-list standard MGMT-ONLY
 permit 192.168.10.224 0.0.0.15
line vty 0 15
 access-class MGMT-ONLY in

The HR deny is before the permits; anything unmatched (e.g. Sales SSH to the server) hits the implicit deny.
