Step 7

Spanning Tree (PVST+), PortFast & BPDU Guard

Goal. Switch to rapid PVST+, take control of which switch is the root bridge, and protect host ports.
Concept. Redundant Layer 2 paths cause loops: frames would circulate forever. STP prevents this by electing a root bridge (lowest priority, then lowest MAC); every other switch picks one root port toward it, and any redundant port is blocked. Cisco runs one tree per VLAN (PVST+); rapid-pvst converges in seconds. In this lab the two SW1–SW2 cables are bundled into Po1, so STP sees a single link and has nothing to block, but it still decides the root, and it protects your edge ports. PortFast lets host ports forward instantly; BPDU Guard shuts a host port if a switch is plugged in.
Before you start. EtherChannel working (Step 6).

Your tasks

  1. Set spanning-tree mode rapid-pvst on both switches.
  2. On SW2 run show spanning-tree vlan 10. Note who the root is (lowest bridge ID, so the lowest MAC by default) and that the only link between the switches is Po1, one logical port, so nothing is blocked.
  3. Make SW1 root for VLANs 10,20 and backup root for 30,99; make SW2 root for 30,99 and backup for 10,20 (load sharing).
  4. Enable PortFast and BPDU Guard on host ports: SW2 Fa0/10-12 and SW1 Fa0/10.

Hints

Hint 1

The easiest root control is spanning-tree vlan <list> root primary|secondary.

Hint 2

Host-port protection: spanning-tree portfast and spanning-tree bpduguard enable (interface mode).

Hint 3

Err-disabled recovery: shutdown, then no shutdown on the port.
