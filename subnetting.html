Step 1

Subnetting (VLSM)

🔒 Complete this step to unlock the rest of the lab.
Goal. Design the addressing plan for the whole lab. Every later step (VLAN IPs, DHCP, OSPF, ACLs) uses your answers.
Concept. Subnetting divides a network by borrowing host bits. VLSM lets each subnet have its own size: sort requirements from largest to smallest and place each subnet right after the previous one, so nothing overlaps. Usable hosts = 2h − 2 (h = host bits); the prefix is 32 − h.

Your tasks

  1. You have 192.168.10.0/24. Required hosts: Sales 100, HR 50, IT 25, Mgmt 10, Router link 2.
  2. For each, find the smallest host-bit count that fits, and thus the prefix.
  3. Starting at 192.168.10.0, allocate in the order given; each network starts where the previous broadcast ended + 1.
  4. Type the network address, prefix number (e.g. 24) and broadcast address in the table, then press Check.

Hints

Hint 1 – host bits

Find the smallest h with 2h − 2 ≥ hosts. Example: 50 hosts → h = 6 (62 hosts) → /26.

Hint 2 – block size

Block size = 2h. The next network = previous network + block size.

Hint 3 – broadcast

Broadcast = next network − 1 (the last address in the block).

Hint 4 – the router link

A point-to-point link needs exactly 2 usable hosts.
